## 📖 About

**University Website** is a static, multi-page website themed around **KL University** (K L Deemed to be University, Vaddeswaram, Andhra Pradesh). It showcases the programs offered in the 2023-24 academic year, the Vijayawada and Hyderabad campuses, campus facilities, student testimonials, a blog-style program page and a contact page with a map.

<img src="https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png" width="100%">

## ✨ Features

| Page | Highlights |
|---|---|
| 🏠 **Home** (`index.html`) | Hero banner with a link to the official site, B.Tech / M.Tech / M.Sc. program lists, "Our Global Campus" (Vijayawada & Hyderabad), facilities (library, playground, canteens, activity center, placement, hostel), student testimonials and an enrollment call to action |
| 🏛️ **About** (`about.html`) | University overview, history and NIRF rankings |
| 🎓 **Courses** (`course.html`) | Full list of programs offered in 2023-24 |
| 📝 **Blog** (`blog.html`) | "Certificate & Online Programs for 2023" post, post categories sidebar and a comment form |
| 📞 **Contact** (`contact.html`) | Embedded Google Map, address / phone / email cards and a contact form (front-end only, not wired to a backend) |
| 📱 **Mobile menu** | Hamburger menu on small screens (slide-in nav via a small inline script) plus CSS media queries |

## 🚀 Getting Started

**Prerequisites:** a modern web browser (Python 3 is optional, for a local server).

1. Clone the repository
   ```bash
   git clone https://github.com/Annepuuday111/University-Website.git
   cd University-Website
   ```
2. Open `index.html` directly in your browser, **or** serve the folder locally:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`

No build step or dependencies are needed. Fonts and icons load from CDNs, so an internet connection is required for full styling.
